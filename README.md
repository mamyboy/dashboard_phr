# สสจ.สตูล แดชบอร์ดสาธารณสุข (PHR Dashboard)

## ภาพรวม
แดชบอร์ดสาธารณสุขสำหรับสำนักงานสาธารณสุขจังหวัดสตูล แสดงข้อมูลหน้ากากอนามัยและตัวชี้วัดสาธารณสุขอื่นๆ

## คุณสมบัติหลัก
- แสดงข้อมูลแบบคงที่ (Static) ที่สร้างจากไฟล์ CSV
- รองรับการแสดงผลบนอุปกรณ์มือถือและเดสก์ท็อป
- กราฟแสดงประสิทธิภาพการตอบกลับรายหน่วยที่ปรับปรุงให้อ่านง่ายขึ้น
- ไม่มีข้อผิดพลาด JavaScript ในการแสดงผล

## การปรับปรุงล่าสุด
### กราฟมิติหน่วย 3 — ประสิทธิภาพการตอบกลับรายหน่วย
- เพิ่มความสูงของแถวกราฟจาก 30px เป็น 36px เพื่อให้มีช่องว่างระหว่างแถวมากขึ้น
- ปรับการตัดข้อความยาวให้เหมาะสมกับขนาดหน้าจอต่างๆ
- เพิ่มระยะห่างด้านบนและล่างของ SVG เพื่อให้กราฟไม่ชิดขอบ
- ปรับการแสดงผลข้อความในกราฟให้ชัดเจนขึ้นบนหน้าจอขนาดต่างๆ

## ไฟล์สำคัญ
- `analyze_daily_interactive.py` - สคริปต์ Python สำหรับสร้างแดชบอร์ดจาก CSV
- `index.html` - ไฟล์แดชบอร์ดที่สร้างขึ้น (อัปเดตโดยอัตโนมัติเมื่อรันสคริปต์)
- `csv/` - โฟลเดอร์ที่มีไฟล์ข้อมูล CSV
- `tests/` - โฟลเดอร์ทดสอบหน่วย

## การติดตั้งและการใช้งาน
1. ติดตั้ง Python 3.11 หรือสูงกว่า
2. รันสคริปต์เพื่อสร้างแดชบอร์ด: `python3 analyze_daily_interactive.py`
3. เปิดไฟล์ `index.html` ในเบราว์เซอร์เพื่อดูผลลัพธ์

## การทดสอบ
รันการทดสอบหน่วยทั้งหมด:
```bash
python3 -m unittest discover -s tests -v
```
